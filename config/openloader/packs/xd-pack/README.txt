Custom symbol replacement resource pack for Minecraft 1.21.1

Files:
- pack.mcmeta: resource pack metadata
- assets/minecraft/font/default.json: vanilla default font with the custom provider
- assets/minecraft/textures/font/xd_lofo.png: logo texture

The character ҈ is replaced in the vanilla default font. The PNG is used as one glyph and scaled to height 8.

Use the character directly in text components. Example:
{"text":"҈"}
